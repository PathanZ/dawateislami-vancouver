# Dawat-e-Islami Canada website (dawateislami.ca)

A static website: plain HTML pages generated by `build.py` from the lists in `content.py`.
No database, no logins, free hosting.

## How to update

| What | Where |
|---|---|
| Centres, Jamia campuses, weekly gatherings, classes, departments, books, videos, donation types | `content.py` |
| Special one-off announcements (they disappear after their date) | `assets/events.js` |
| Online donation link (Zeffy, CanadaHelps…) | `DONATE_URL` in `content.py` |
| Receipt and contact forms | `RECEIPT_GFORM` / `CONTACT_GFORM` in `content.py` (Google Form field ids) |
| Colours and layout | `assets/style.css` (navy = national signature colour, gold = Donate, pink = sisters) |

After editing `content.py`, run `python3 build.py` to regenerate every page. Anything written as `TBD`
shows a yellow TBD label on the site.

## Pages

`index`, `about`, `departments` (+ `departments/<name>`), `centres` (+ `centres/<name>`),
`events` (gatherings and classes, + `events/<name>` and `courses/<name>`), `jamia`, `islam/<pillar>`,
`donate` (accepts `?purpose=zakat&centre=<centre-slug>`), `receipt`, `contact`, `privacy`, `terms`, `404`.

## Pictures

Pictures are linked from the Dawat-e-Islami Canada media store and dawateislami.co.uk. The
"Download pictures" GitHub Action copies them into `assets/img/ext/` so the site no longer depends
on those servers, then `tools/optimize_images.py` makes small WebP copies in `assets/img/opt/` for fast
mobile loading. `build.py` uses the smallest local copy automatically once it exists.

## Hosting

Cloudflare Pages: connect this repo, no build command, output directory `/`.
`_redirects` and `_headers` are read by Cloudflare.
