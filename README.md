# Dawat-e-Islami Canada website

Website for **dawateislami.ca**. Plain HTML pages generated by a small Python script.

## Update the site

| To change | Edit | Then |
|---|---|---|
| Events and announcements | `assets/events.js` | push |
| Centres, services, departments, donation emails, contact details, social links, online donation link | `content.py` | `python3 build.py`, then push |
| Page layout and text | `build.py` | `python3 build.py`, then push |
| Look and colours | `assets/style.css` | `python3 build.py`, then push |

Event posters go in `assets/img/events/`. A hero video can be added as `assets/video/hero.mp4` (under 10 MB) with a still image `assets/img/hero.jpg`.

## Hosting

Cloudflare Pages, connected to this repository. Build command: none. Output directory: `/`.
`_redirects` sends the old Vancouver pages to https://dawateislamivancouver.ca.
